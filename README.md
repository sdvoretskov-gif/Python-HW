# Учебный пПроект: Автоматизация тестирования 

интернет-магазина https://www.saucedemo.com/inventory.html
онлайн калькулятор https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html
## Цель
Провести функциональное тестирование ключевого пользовательского 
сценария: 
калькулятор - операции сложения целых чисел
интернет-магазин - авторизация → выбор товара → добавление в корзину 
→ оформление заказа.

## Технологии и инструменты
* **Язык программирования:** Python 3.x
* **Фреймворк тестирования:** pytest
* **Инструмент Selenium:** для взаимодействия с веб-страницей
* **Генератор отчётов:** Allure (интеграция с pytest через плагин 
* `allure-pytest`)
* **Среда разработки:** PyCharm

## Структура проекта
Проект организован по паттерну **Page Object Model (POM)** 
для повышения переиспользуемости кода и удобства поддержки.

## Настройка окружения
Установите зависимости. Откройте терминал в PyCharm и выполните:
pip install -r requirements.txt
Настройте WebDriver. Скачайте соответствующий драйвер для вашего браузера
(например, ChromeDriver для Google Chrome).
Важно: версия драйвера должна совпадать с версией установленного браузера.
Для упрощения можно использовать webdriver-manager:
pip install webdriver-manager
Затем в коде укажите webdriver.ChromeManager() 
или задайте путь через переменную окружения.
 

## Запуск тестов
Для запуска всех тестов используйте команду:
pytest -v -s
Чтобы сгенерировать отчёт в формате Allure, выполните:
pytest --alluredir result
allure generate .\result -o ./reports
allure serve reports

## Особенности реализации
Allure-тегирование. Для каждого тестового сценария и(или) шага используются 
декораторы Allure:
@allure.epic("Калькулятор")
@allure.feature("Сложение")
@allure.story("Операция сложения целых чисел")
@allure.title("Сложение целых чисел")
@allure.description("Пример сложения целых чисел в калькуляторе"
                    "на страничке https://bonigarcia")
@allure.severity("Critical")

## Просмотр отчёта
После генерации откройте в браузере файл reports/index.html 
для просмотра отчёта Allure в наглядном виде:
allure serve result
Важные замечания
Убедитесь, что в PyCharm правильно настроен интерпретатор Python 
и виртуальное окружение.
При возникновении ошибок проверьте соответствие версий 
Chrome и ChromeDriver, а также корректность пути к драйверу в коде.
